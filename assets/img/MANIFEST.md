Supply note: files were staged by the Foundry supply line
(~/workspace/fleet-ops/foundry-supply/fantasy-v3/, with its own manifest)
and the Steam files were independently byte-matched against the CDN
originals during this build. The Season 10.5 overview banner in the
supply set was not shipped: it is an infographic for the game season,
not the Ignite beat these surfaces carry.

Rotation 24 note (2026-10-14): the 42 portrait rows after the first 12
close the hero portrait set. Every one is the Foundry staged file copied
byte for byte (MD5 verified against the supply manifest before landing),
so the strip now carries the full 54-hero roster the official heroes
page publishes, grouped by the role that page tags. Deadpool's official
tag covers all three roles; his portrait stands once, with the
Duelists, and his file carries the small name and role plate the game
itself distributes in the lower area, exactly as staged. The 12
portraits shipped in rotation 23 are unchanged.

Presentation rework note (2026-10-15): hero-key-art.jpg and
season-key-art.jpg were recompressed for their slots in the v4
presentation pass (same images, same dimensions, same crops;
JPEG quality 82 / 78). 318,827 B to 203,890 B and 765,510 B to
132,940 B. Provenance rows above are unchanged; the 54 hero
portraits are byte-untouched.

Image density pass (2026-10-24): NO new image files were added.
The 54 hero portraits and the stills above were reused on more
surfaces: all four main surfaces (home, players, season, league)
now carry a hero ribbon or the full grouped 54-hero wall;
still-pool.jpg and still-playoffs.jpg (rows above) now also run as
art bands on home and season; spotlight cards and row faces reuse
hero portraits as a pro's listed signature hero. Framing rule,
unchanged from round 3: a portrait is always a game hero, never a
pro player — beside a pro it is the first hero the pool data lists
for that pro, it renders only where the data lists one, and every
surface that mixes the two says so in words.


Responsive image pass (2026-10-24, Claude bundle 2026-10-24 item 5):
the binaries TGZ (fantasy-images-binaries.tgz) never downloaded, so the
binaries were REGENERATED in-repo with the patch's own scripts: the 43
Steam store screenshots below were fetched by
`node scripts/pull-steam-art.mjs` (public Steam art, app 2767030, pulled
2026-10-24), and every responsive variant was produced by
`python3 scripts/optimize-images.py` (AVIF + WebP at 640/1024/1440 for
the stage stills and the six key/still files already listed above; AVIF +
WebP for all 54 hero portraits). System Pillow 10.2 cannot write AVIF,
so the optimiser ran under a local venv with Pillow 13 (the script's own
requirement is Pillow 11.3+); its outputs are the files in
assets/img/image-meta.json (regenerated alongside). Pages load only the
generated variants; the JPG/PNG originals stay as the source of truth.
Hero art is always labelled as the game hero, never as the player.
